# PDF RAG Chatbot

A Multi-PDF Retrieval-Augmented Generation (RAG) Chatbot built using:

* Google Gemini 2.5 Flash
* ChromaDB
* Sentence Transformers
* Gradio
* PyMuPDF

## Features

* Upload multiple PDF documents
* Extract and process PDF content
* Generate semantic embeddings
* Store embeddings in ChromaDB
* Retrieve relevant information
* Answer questions using Gemini AI
* Interactive Gradio interface

## Tech Stack

* Python
* Google Colab
* Gemini API
* ChromaDB
* Sentence Transformers
* Gradio

## Workflow

PDF Upload → Text Extraction → Chunking → Embeddings → ChromaDB → Retrieval → Gemini → Answer Generation
